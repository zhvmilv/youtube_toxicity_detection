# youtube_toxicity_detection
Классификация токсичных комментариев на русском языке

ML-модель, которая определяет токсичные комментарии на русском языке. Обученная модель применена к реальным данным: комментариям YouTube под трансляцией судебного заседания Бишимбаева (11.04.2024).


Задача
1. Обучить классификатор «токсичный / нетоксичный» на размеченном датасете.
2. Собрать комментарии с YouTube с помощью парсера.
3. Оценить долю токсичных комментариев в обсуждении резонансного события.

Данные
1. Обучающая выборка: Russian Language Toxic Comments (Kaggle). 14 412 комментариев, из них 4 826 токсичных (≈33%).
2. Данные для анализа: 1 193 комментария верхнего уровня, собранные с YouTube.
